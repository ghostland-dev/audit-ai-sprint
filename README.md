# Audit Sprint

SaaS for running and tracking audits by project and team.

## Features

- Audits, projects and reports
- Team management and billing
- Supabase back-end, Zustand state

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Zustand
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/audit-ai-sprint.git
cd audit-ai-sprint
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
